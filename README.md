# 3D Glasses Customizer

An interactive 3D glasses visualization built with Three.js.

## Features
- Interactive 3D glasses model
- Customizable frame and lens colors
- Real-time color updates
- 3D model interaction with OrbitControls

## Technologies
- JavaScript
- Three.js
- GLTFLoader
- OrbitControls
- lil-gui
